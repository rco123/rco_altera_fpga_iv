    LED ON OFF

    실습키트의 LED 16비트를 ONOFF하는 과정을 실습니다.

    해당 값에 대한 비트에 LED 가 ON OFF되는지 확인한다.

    PIN 테이블

    핀 번호 신호
    PIN_B3 LED_A[7]
    PIN_B4 LED_A[6]
    PIN_B5 LED_A[5]
    PIN_B6 LED_A[4]
    PIN_B7 LED_A[3]
    PIN_B8 LED_A[2]
    PIN_B9 LED_A[1]
    PIN_B10 LED_A[0]
    PIN_B13 LED_B[7]
    PIN_B14 LED_B[6]
    PIN_B15 LED_B[5]
    PIN_B16 LED_B[4]
    PIN_B17 LED_B[3]
    PIN_B18 LED_B[2]
    PIN_B19 LED_B[1]
    PIN_B20 LED_B[0]

    VHDL 코드

    
library ieee;
use ieee.std_logic_1164.all;

entity led_test is
   port(    LED_A   : out std_logic_vector(7 downto 0);
                LED_B   : out std_logic_vector(7 downto 0) );
end led_test;


architecture button_design of led_test is
begin

    LED_A <= x"F0";
    LED_B <= x"0F";

end button_design;
